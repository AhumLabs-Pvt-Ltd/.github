# Ahum

Ahum is an open developer community for maritime software, run by Ahum Labs. We build
small, well-tested tools and shared knowledge that make ship operations data easier to
work with: certificate rules, vessel schemas, synthetic test fleets, and MCP servers
that let AI agents use that knowledge. Everything here uses synthetic data only. No real
ship, client or crew data is ever committed.

## Repositories

- [maritime-context-pack](https://github.com/AhumLabs-Pvt-Ltd/maritime-context-pack): certificate knowledge cards, JSON schemas, a synthetic fleet, and an MCP server.
- [repo-template](https://github.com/AhumLabs-Pvt-Ltd/repo-template): the TypeScript starter every new Ahum tool begins from.
- [community-site](https://github.com/AhumLabs-Pvt-Ltd/community-site): the community landing page.
- [.github](https://github.com/AhumLabs-Pvt-Ltd/.github): this profile, the code of conduct, and default issue and PR templates.
